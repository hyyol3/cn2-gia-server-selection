## 三网回程 CN2 GIA 里的“三网”，到底指什么

CN2 是中国电信的下一代承载网，线路号 AS4809。GIA 是其中一个等级，回程基本全程走 59.43 节点，少数没有接入 GIA 的省内节点会回落到 202.97 借道。它的价值在于优先级高、用的人少，白天正常不丢包，晚高峰丢包率也压得很低。代价是 GIA 整体出口带宽不大，遭遇攻击时容易波动。

真正意义上的三网回程 GIA，是电信、联通、移动三家用户的回程流量全部被路由到 GIA 上。做起来贵，等于要买三份回程带宽。市面上大量标着“CN2 GIA”的机器只优化了电信：电信回程走 GIA，联通走普通 163，移动走 CMI 或更差的国际链路。白天看不出差别，晚高峰联通和移动用户就开始转圈。

LightLayer 圣何塞这套属于第三种组合。电信走 CN2 GIA，联通走 AS4837（联通国际线路），移动走 CMIN2（移动国际精品网）。这三条都不是普通公网，但只有电信那条是 GIA。所以它不满足“三网全 GIA”的定义，实际晚高峰表现要看三条线各自的状态。别把“三网优化”和“三网 GIA”当成同一件事，这是选机器时最容易踩的坑。

验证方法不复杂：找客服要测试 IP，用 MTR 分别从电信、联通、移动网络跑一遍回程。三网都出 59.43 才算真三网 GIA；出现 202.97、4837、CMIN2 混跑，就是优化线路。延迟方面，美西 CN2 GIA 一般在 150–170ms 量级，欧洲 200ms 上下，香港 20–30ms（这个数字来自商家自述，不是中立实测）。LightLayer 圣何塞的具体延迟没有可靠的公开数据，不同来源口径差异很大，自己测为准。

## 哪些人不用考虑

**一定要三网全 GIA 的人。** LightLayer 走的是三家各用各的优质线路，电信那条是 GIA，联通移动两条不是。要求三网回程全部落在 59.43 上的，直接去看专门标三网回程 GIA 的商家，别在这里绕。

**需要明确退款条款的人。** 公开页面里没有清晰的退款政策说明，2025 年初的一份第三方测评也提到“退款政策模糊，建议下单前跟客服确认”。促销款还限购 2 台、1 小时未付款取消。这类情况下第一台机器必须走月付。

**对原生 IP 有刚需的人。** 公开资料没有承诺原生 IP。做流媒体解锁、多账号运营的，下单前问清楚 IP 段性质，别等开通了再扯皮。

**高 I/O 场景。** 有测评提到默认 SSD 平均读写约 220MB/s（2025 年初的第三方口径），跑数据库、处理大文件不合适，这类需求应该直接看独服或者其他家。

**流量只有几十 GB 的轻度用户。** 年付大配置是浪费，LITE 月付 $4.90 就到顶了。
